# Welfare Module

## 目的

Welfare Moduleは、生存不安を減らし、人が好きなことに集中できる状態を支えるための生活支援を扱います。

支援は参加者を縛るためではなく、自由な活動の土台を増やすために設計します。

## このモジュールが解決する問題

多くの人は、生きるために望まない仕事や環境を受け入れざるを得ません。

この設計では、生活基盤を共同で支え、自由な活動を可能にすることを目指します。

## 責任範囲

- 食
- 住
- 通信
- 教育
- 医療・健康支援
- 生活アクセス
- 相互扶助
- 支援の透明性

## 責任範囲外

- 強制的な共同生活
- 離脱不能な福祉制度
- 特定思想への依存
- 支援を条件にした服従要求

## 他モジュールとの関係

Welfareは、Economyの生活アクセス、Identityの対象確認、Governanceの支援ルール、Arbitrationの不服申し立てと接続します。

生活支援が権力化しないよう、支援条件、判断基準、変更履歴を透明にする必要があります。

## 初期設計メモ

初期は小さな相互扶助、共同購入、生活コスト削減、学習支援など、法的・運用的リスクの低い領域から検討します。

支援は依存を作るためではなく、選択肢を増やすためのものとして設計します。

## 未解決の問い

- 生活支援と依存の境界
- 公平性の設計
- 悪用防止
- 支援判断の透明性とプライバシーをどう両立するか
