# Roadmap

この世界設計は段階的に設計・実装します。フェーズの流れは [04-transition-roadmap.md](../../assets/diagrams/04-transition-roadmap.md)、普及時に強制へ寄らないための考え方は [08-non-coercive-adoption.md](../../assets/diagrams/08-non-coercive-adoption.md) にあります。

## Phase 0: 設計基盤

- GitHubリポジトリの整備
- VisionとPrinciplesの作成
- 用語集の整備
- ProposalとDecisionの運用開始
- Non-goals、Safety、Threat Modelの作成
- 初期モジュールREADMEの作成
- Founder Non-privilege Decisionの作成
- Research IndexとIssue下書きの作成

### Phase 0 完了条件

- Vision / Principles / Architecture / Roadmapが存在する
- Glossaryに初期用語が整理されている
- Proposal / Decisionの運用が始まっている
- Non-goalsとThreat Modelが存在する
- Code of ConductとSafety方針が存在する
- 初期モジュールREADMEが揃っている
- Founder Non-privilegeがDecision化されている
- Research IndexとIssue下書きが存在する

## Phase 1: 初期組織

- 最初の組織運営
- 参加者の募集
- 基本的なガバナンス実験
- 小さな生活支援や協力の仕組みを検証

### Phase 1 完了条件

- 初期組織の運用記録がある
- 小さな協力・相互扶助・生活支援の実験が記録されている
- 重要な判断がDecisionに残っている
- 権限と役割が文書化されている
- Code of ConductとSafety方針に基づく初期運用が行われている

## Phase 2: モジュール実験

- Identity
- Reputation
- Economy
- Welfare
- Governance
- Arbitration
- Infrastructure
- Audit
- Norms
- Public Safety
- Federation

各モジュールを小さく実験します。

### Phase 2 完了条件

- 各モジュールの責任範囲と責任範囲外が明確になっている
- Reputationが差別や階級化につながらない安全境界を持つ
- Auditが監視化しない公開情報・保護情報の境界を持つ
- EconomyとWelfareの実験が専門家レビュー要否を明示している
- モジュール間の責任侵食がThreat Modelでレビューされている
- Normsが国家法の違法な代替に見えない安全境界を持つ
- Public Safetyが警察代替や自警団化に見えない安全境界を持つ
- Federationが中央支配組織に見えない安全境界を持つ

## Phase 3: 組織連盟

複数の組織が共通ルールやプロトコルで協力できる状態を作ります。

### Phase 3 完了条件

- 複数組織が共通プロトコルで接続できる
- 組織ごとの自律性とフォーク可能性が保たれている
- 組織間のReputation、Audit、Arbitrationの接続方針がある
- データポータビリティと離脱手続きが文書化されている

## Phase 4: 世界共通協力基盤

国境を超えた協力、信用、生活支援、教育、経済圏を形成します。

### Phase 4 完了条件

- 国境を超えた参加と翻訳運用が機能している
- 法制度差を前提にした運用方針がある
- 生活アクセス、信用、仲裁、監査が地域差と両立している
- 不要な国家・社会との敵対を避けるSafetyレビューが機能している

## Phase 5: 国家機能の縮小

特定組織が国家を支配するのではなく、人々が国家を意識しなくても協力し生活できる状態を作ります。

この段階でも、強制的な置き換えや政治的な対立拡大は目指しません。より便利で透明な協力基盤が自然に選ばれる状態を目指します。

### Phase 5 完了条件

- 国家以外でも担える協力、生活支援、信用、仲裁、教育、インフラの選択肢が増えている
- 人々が複数の共同体や組織へ自由に所属できる
- 離脱可能性、フォーク可能性、プライバシー、安全方針が保たれている
- 強制ではなく利便性による採用が維持されている
