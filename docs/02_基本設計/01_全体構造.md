# 全体構造

## 文書と責務

| 領域 | 正本 | 役割 |
| --- | --- | --- |
| 目的・原則・構造 | `docs/ja/` | ビジョン、原則、アーキテクチャ、ロードマップ、安全境界を定義する |
| モジュール | `modules/ja/` | アイデンティティ、経済、福祉、ガバナンスなどの責務を分離する |
| 提案・意思決定 | `proposals/ja/` / `decisions/ja/` | 変更提案と重要な判断をレビュー可能にする |
| 調査・用語 | `research/ja/` / `glossary/` | 前提の検証と表現の一貫性を支える |
| 図表 | `assets/diagrams/` | 文書間の関係を視覚化する |
| 公開サイト | `world-foundation-site` | 正本Markdownを同期し、Webで公開する |

## 公開と翻訳

1. 日本語の設計本文を`docs/ja/`などの正本に置く。
2. 英語版は`docs/en/`などの対応する公開原稿として管理する。
3. `world-foundation-site`が正本を同期して公開する。

`docs/ja`と`docs/en`のパスは公開同期の入力であるため、内部分類のためだけに移動しない。
