# 文書一覧

このディレクトリは、World Foundation設計の公開原稿と、リポジトリ内の文書分類を管理する入口です。

`ja/`と`en/`は公開サイトへ同期する言語別の正本です。言語コードは公開URLと同期設定の契約であるため、この変更では移動しません。

| 分類 | 内容 |
| --- | --- |
| [01_要件定義](01_要件定義/01_対象と要件.md) | 設計対象、原則、対象外の案内 |
| [02_基本設計](02_基本設計/01_全体構造.md) | 全体構造、モジュール、運用、安全、移行の案内 |
| [日本語公開原稿](ja/README.md) | 公開サイトへ同期する日本語の詳細設計 |
| [英語公開原稿](en/README.md) | 公開サイトへ同期する英語版 |

詳細な設計本文を変更するときは、`ja/`を正本として更新し、翻訳方針に従って`en/`との対応を確認する。
