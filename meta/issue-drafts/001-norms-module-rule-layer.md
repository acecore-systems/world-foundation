# Norms Module / Rule Layerを追加するか検討する

## 背景

World Foundation Designでは、ルール、規約、権利、義務、例外、改定手続きが必要になる。現在はGovernance、Arbitration、Safety、Non-goalsに分散している。

## 目的

国家法を違法に代替せず、協力基盤内の自発的なルール層をどう設計するか検討する。

## 検討論点

- ルール、原則、規約、Decisionの境界
- 権利と義務
- 例外処理
- 改定手続き
- 国家法との接続
- GovernanceとArbitrationとの境界
- 私的制裁化を避ける条件

## 安全上の注意

国家司法の完全代替、違法な私的法体系、私的制裁、思想統制に見える設計は避ける。
